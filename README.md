# Cars Inventory Search
This project is a car inventory search tool, built with JavaScript, HTML, CSS, and Webpack. It allows users to filter cars based on various attributes such as year, brand, and color. The primary focus is on demonstrating how to build a dynamic search interface.

## Features
- Car Filtering: Search by brand, year, or color.
- Interactive Interface: Built with vanilla JavaScript and responsive design.

You can try the live demo [here](https://juliettkhar.github.io/CarsInventorySearch/).
